## 勉強

### RPC(Remote Procedure Call)とは
Procedure(プロシージャー)

RPCとは</br>
そのAPIが提供したいサービスをProcedureとしてサーバー上に実装して、それをAPIを使う側であるクライアントコードから直接呼び出すようにする

ex.

ローカル(hello関数が存在しない場所)からhello関数を呼び出す的な


### gRPCとは
Googleが開発、提案したRPCのプロトコルがgRPC。</br>
RPCを具現化するための方式の一つ

- gRPCがRPCを実現させるために使っている技術
  - HTTP/2
    - 実現させるには二つが必要
      - クライアントからサーバーに、呼び出す関数と引数の情報を伝える
      - サーバーからクライアントに、戻り値の情報を伝える
    - gRPCではpostリクエストとそのレスポンスを使ってこれを実現している
      - 呼び出す関数の情報: リクエストのパスに含める
      - 呼び出す関数に渡す引数: HTTPリクエストボディに含める
      - 呼び出した関数の戻り値: HTTPレスポンスボディに含める
  - Protocol Buffers
    - 呼び出した関数の引数、戻り値の情報はをプレーンテキストで書くのではなく、シリアライズ方式を用いて変換してリクエストレスポンスに含める
    - シリアライズ方式とは
      - データを一連のバイトに変換するプロセス。
      - ネットワーク経由で効率的に転送できる。(ファイルサイズを小さくできる)
      - データの送受信や保存が高速、通信での遅延が少なくなるというメリット
